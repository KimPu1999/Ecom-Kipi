Typography uses Inter or the approved equivalent. Display 48/56, H1 36/44, H2 28/36, H3 22/30, body 16/24, small 14/20, caption 12/16. Weight range: 400 regular, 500 medium, 600 semibold, 700 bold.

Spacing uses a 4 px base: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80. Radii: 8 default, 12 cards, 999 pills. Shadows are subtle and reserved for elevated surfaces.

## Responsive rules

Reference frames: 375 mobile, 768 tablet, 1440 desktop. Desktop content max width is 1200–1280 px. Mobile uses a 16 px gutter; tablet 24 px; desktop 32–40 px. Product grids are 2 columns mobile, 3 tablet, 4 desktop.

## Component inventory

Buttons, inputs, selects, checkboxes, radios, search, breadcrumbs, tabs, dropdowns, modals, cards, product cards, category cards, filters, pagination, toast, skeleton, empty state, error state, header, footer, admin sidebar, data table, stat card, confirmation dialog.

Every interactive component must define default, hover, focus-visible, active, disabled, loading, error, and success variants where applicable. Focus rings must meet accessibility contrast requirements.
