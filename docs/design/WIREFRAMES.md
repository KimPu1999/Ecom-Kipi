# Responsive Wireframes

## Shared layout

~~~text
Desktop 1440: [Announcement] [Header + search] [Nav] [12-col content] [Footer]
Tablet 768:   [Announcement] [Header/search] [compact nav] [8-col content] [Footer]
Mobile 375:   [Header/menu/search] [single-column content] [sticky action where useful]
~~~

## Home

Announcement, header, nav, hero with primary CTA, category shortcuts, featured grid, new arrivals, trust strip, promotion, newsletter, and footer.

## Product listing

Breadcrumb, title/count, filter/sort toolbar, filter drawer on mobile, product grid, pagination, empty/error state.

## Product detail

Gallery and product information are side-by-side on desktop, stacked on mobile. Variant and quantity controls remain adjacent to the primary Add to cart action. Related products follow shipping information.

## Cart and checkout

Cart uses a two-column desktop layout and one-column mobile layout. Checkout uses a clear sequence: contact, address, shipping, payment, review. The order summary remains visible or becomes a sticky bottom summary on mobile.

## Admin

Sidebar, top bar, page content. Tables collapse into cards on mobile. Primary actions are visible above the fold; destructive actions require confirmation.
