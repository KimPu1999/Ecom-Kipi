# Phase 1 Acceptance Criteria

- [ ] Product vision, goals, personas, scope, assumptions, and dependencies approved.
- [ ] MVP must/should/future scope separated.
- [ ] Roles, permission catalog, ownership rules, and future seller boundary documented.
- [ ] Customer, admin, and future marketplace journeys mapped.
- [ ] Business rules cover stock, money, checkout, payment, cancellation, and authorization.
- [ ] All unresolved tax, shipping, payment, currency, guest checkout, and returns decisions are visible.
- [ ] Architecture, sitemap, ERD, API contract, wireframes, screen specifications, design system, and backlog exist.
- [x] Figma file or handoff status is recorded without claiming unavailable artifacts.
- [ ] Backend Phase 3 endpoints and schema are traceable to the requirements.
- [ ] Phase 2 implementation can start without redesigning the domain model.
